ILeadsOutlookAgent - instrucciones rapidas
===========================================

Esto deja que la web de ILEADS lea los correos de tu Outlook para poder
mostrarte el historial con cada cliente. Solo LEE correos, nunca envia
ni borra nada.

COMO USARLO
-----------
1. Abre Outlook de escritorio (el programa, no la pagina web) e inicia
   sesion con tu cuenta normal, como siempre.

2. Haz doble clic en "ILeadsOutlookAgent.exe".

3. Si Windows muestra un aviso azul ("Windows protegio su PC"):
   pulsa "Mas informacion" y luego "Ejecutar de todas formas".
   Es normal, solo pasa la primera vez.

4. Se abrira una ventana negra con texto. Dejala abierta (puedes
   minimizarla) mientras uses la web de ILEADS.

5. En la web, entra en un cliente -> "Establecer comunicacion" ->
   "Agente local". Deberia mostrarte los ultimos correos con ese cliente.

Para cerrarlo, simplemente cierra esa ventana negra cuando termines.

PARA QUE SE ABRA SOLO AL ENCENDER EL ORDENADOR (opcional)
----------------------------------------------------------
Si quieres no tener que abrirlo cada vez a mano:
1. Guarda "install_autostart.ps1" en la MISMA carpeta que el .exe.
2. Haz clic derecho sobre "install_autostart.ps1" -> "Ejecutar con PowerShell".
   (Si Windows pregunta, permite la ejecucion).
3. Listo - a partir de ahora se abrira solo cada vez que inicies sesion.
